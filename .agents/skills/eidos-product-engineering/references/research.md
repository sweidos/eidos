# Research methodology

## Sources (prefer in order)
1. Current Eidos source, tests, types, package exports
2. Git history, merged PRs, open issues
3. Published npm package vs repo tip
4. Live docs site (sweidos.vercel.app)
5. Official docs for dependencies (Workbox concepts, Web Locks, Background Sync, IndexedDB, TanStack Query docs)
6. Credible public feedback (issues, discussions) — never invent

## Rules
- Do not treat downloads as unique users or production deployments.
- Do not conclude “marketing is the only problem” before evaluating correctness, onboarding, differentiation.
- Label every claim: **verified** / **hypothesis** / **unknown**.
- Include source URLs or file paths for verified findings.
- Re-verify historical audit claims against current main before acting.
